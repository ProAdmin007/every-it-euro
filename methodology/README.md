# Methodology

This folder is the reference for **how Every IT Euro works**: what we call European, which companies we list, which sources we accept, how the tools reach their results and how translations are handled. The website shows a public summary (`about.html`, `alternatives.html#classification`, `sovereignty.html`); these documents hold the full rules.

| Document | Answers |
|---|---|
| [01 — What makes a company European](01-european-company.md) | The criteria, the five classifications, decision rules and edge cases |
| [02 — The company database](02-company-database.md) | When a company is included, removed or moved to the watchlist; required fields; verification |
| [03 — Sources and evidence](03-sources-and-evidence.md) | Which sources count, how claims are cited, quotes, figures and dates |
| [04 — Editorial principles](04-editorial-principles.md) | The position of the site, tone and wording rules |
| [05 — Tools and calculations](05-tools-and-calculations.md) | The €100 explorer, the sovereignty assessment, worked examples with numbers |
| [06 — Languages](06-languages.md) | Which content is translated, what stays English, which version prevails |

## How to use these documents

- **Before changing content or data**, check the relevant document. If a case is not covered, decide it, then write the decision down here so the next case is treated the same way.
- **When a rule changes**, update this folder, the public summary on the website (`about.html`, `alternatives.html#classification`) and, where needed, existing entries — in one change.
- **Open questions** are listed at the end of each document. They are cases where current practice is not yet consistent or a decision is still needed.

Practical step-by-step instructions (running the review script, adding a company, publishing) are in [`MAINTAINING.md`](../MAINTAINING.md).
